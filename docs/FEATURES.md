# v0.2.0 功能范围

| 模块 | 已实现 | 边界 |
| --- | --- | --- |
| 登录 | 验证码、限速、bcrypt、撤销/到期会话、退出、锁屏解锁 | 公开注册关闭；限速和验证码保存在单实例内存，重启失效；多副本需共享实现 |
| 权限 | 菜单/按钮权限、角色关联、用户数据范围 | 角色/菜单/部门变更与角色分配仅超级管理员；数据范围当前用于用户查询、详情、修改、删除和导出 |
| 系统管理 | 用户、角色、菜单、部门、岗位、字典、参数、通知 CRUD | XLSX 用户导入最多 500 行，逐行权限/数据范围校验、整批事务；不支持旧 XLS；CSV 导出最多 10000 条 |
| 字典与参数 | 数据库实时读取、筛选、选项接口 | 验证码由环境配置控制，公开注册始终关闭；参数配置不用于保存密钥 |
| 通知 | 公告内容、顶部列表、已读与阅读人 | 无推送服务；富文本仅供受信任的公告管理者编辑 |
| 审计 | 登录结果、修改操作路径/操作者/耗时 | 不记录请求体和令牌；部分鉴权前失败不写操作日志；未实现日志定期归档 |
| 在线用户 | 当前有效会话、强制退出 | 列表最多 100 条；强退只允许超级管理员 |
| 服务监控 | 主机内存、核心数、操作系统、服务运行时长 | 不采样 CPU 分时占比、不显示磁盘/JVM 模拟指标，空值表示未采集 |
| 上传 | PNG/JPEG/WebP 解码后重新编码 PNG、头像 | 最大输入 5 MB、4096×4096；普通用户仅上传自己的头像；公开图片路径；无通用文档上传 |
| 系统配置 | 站点设置、易支付 V1/V2 下单与验签、订单查询与幂等收款记录、SMTP 发送、AES-GCM 加密 | 管理接口仅超级管理员；无退款/钱包/业务发货、邮件队列；真实商户和外部邮箱需部署方联调 |
| 代码生成 | 元数据、模型和分页查询示例、预览与 ZIP | 非完整 CRUD；不运行用户 SQL、不自动注册路由；列编辑选项暂不保存；unsigned/decimal 等类型接入前需核对 |
| 缓存/任务 | Redis INFO/SCAN/应用前缀预览清理；UTC 白名单任务 CRUD、暂停恢复、执行、日志/导出 | Redis 可选；管理操作仅超级管理员；非任意代码调度；验证码/限流仍为单实例内存 |

未实现接口不会返回伪造成功。源码保留上游部分未启用视图，方便后续迭代。MySQL 5.7 用于兼容测试；新部署建议使用仍受维护的 MySQL 版本。

五项新增能力的接口、限额和升级方式见 [INTEGRATIONS.md](INTEGRATIONS.md)。
